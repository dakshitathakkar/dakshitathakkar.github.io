# Dakshita Thakkar

Personal portfolio for my work in AI infrastructure and backend engineering.

Live website: https://dakshitathakkar.github.io/

## Updating the site

Edit `index.html`, `styles.css`, `interactions.css`, or `site.js`. Images live in `images/`. Push changes to `main`; GitHub Pages publishes the repository root. No build step is required.

## Local preview

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.
